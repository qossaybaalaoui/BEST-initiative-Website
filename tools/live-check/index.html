Live check against Excel

Change anything in a BEST calculator workbook in Excel, save it, and drop it here. The engine recalculates the file from its own formulas and inputs and compares every formula cell with the result Excel saved.

  1. In Excel, open the PE or ethylene calculator and change any inputs.
  2. Save the workbook (.xlsx). Excel stores its results in the file.
  3. Drop the file below. It is read in this browser and never uploaded.
