# Page builder

The HTML pages are generated by these scripts so that the head, header, footer and
shared sections stay identical everywhere.

```
python3 _src/pages.py .
```

Run it from the repository root after editing any script or `assets/css`/`assets/js`
(the CSS/JS links get a new version stamp, so browsers fetch the updated files).

- `pages.py`       page shell, home, BEST Chemicals overview, Data Centers, Tools, stubs
- `about.py`       About page and shared components (icons, tiles, stepper, tabs)
- `products.py`    BEST Chemicals → Products
- `methodology.py` BEST Chemicals → Methodology
